# Code of Conduct

## Purpose

This code protects a respectful and safe project community. It applies to all project spaces and
project events.

## Expected Conduct

- Use respectful and direct language.
- Discuss the work, not the person.
- Accept technical correction.
- Give clear and useful feedback.
- Respect different experience levels.
- Respect privacy.
- Report unsafe conduct privately.

## Prohibited Conduct

- harassment
- discrimination
- threats
- personal attacks
- sexual attention
- publication of private information
- deliberate disruption
- retaliation after a report

## Reports

Do not report conduct incidents in a public issue. Email `conduct@joinotto.com`.

The maintainers will acknowledge a report within five business days.

## Response

The maintainers will:

1. protect the reporter's privacy
2. review the available evidence
3. avoid conflicts of interest
4. document the decision
5. apply a proportionate response
6. prevent retaliation

## Enforcement Actions

The maintainers can apply these actions:

1. private correction
2. formal warning
3. temporary participation limit
4. permanent removal

The action depends on severity, impact, and prior conduct.

## Appeals

A person can request one appeal. An uninvolved maintainer must review the appeal. The appeal
decision is final.

## Maintainer Conflict

An accused maintainer must not review the report. Another maintainer or an external reviewer must
manage the case.
